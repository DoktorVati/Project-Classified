# Project-Classified
Project Classified is a wave based survival game where the player must survive endless rounds of spiders, zombies, scorpions, and even bigger spiders! Collect powerup drops for ammo and health and remember to aim for the head.

You are equipped with an Assault Rifle and an Axe. Watch your health!

The only way to exit this game is by using the windows button to close out. 

I developed this product several years ago and this is one of my earlier projects.
